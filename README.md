# Удивительный Цифровой Цирк

Иммерсивный фан-сайт по вселенной *The Amazing Digital Circus* (Glitch Productions).

## Запуск

Просто открой `index.html` в браузере. Локально удобно так:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Зависимостей и сборки нет.

## Что внутри

- `index.html` — разметка
- `index.css` — стили, эффекты, `data-corruption` 0..6
- `App.js` — поведение: глаза, кнопка, заголовок, деградация
- `assets/characters/` — фотографии персонажей
- `TZ` — техническое задание

## Поведение

Сайт стартует как «обычный» цирковой шатёр и постепенно тускнеет: плёнка CRT темнеет, цвета уезжают, появляется тинт «Бездны». Уровень развала живёт в `data-corruption` на `<body>` и масштабирует все эффекты через CSS-переменные.

- Заголовок «УДИВИТЕЛЬНЫЙ ЦИФРОВОЙ ЦИРК» постоянно «ломается» (RGB-split, skew). На hover — подмена букв глитч-символами.
- Два глаза — синий и красный — следят за курсором. У синего долгий «лаг», у красного — резкий рывок. Они расходятся во времени, иногда дёргаются «не туда».
- Кнопка «ВЫХОД» умная: иногда замирает (тогда её можно поймать), иногда обещает остаться, но в момент клика убегает. Каждое попадание усиливает развал. На шестое — сайт «абстрагируется».
- При клике по любому интерактиву на 0.7с поверх ленты пробегает CRT-сбой с RGB-сдвигом.
- Карточки персонажей наклоняются при движении курсора (3D-tilt) и «глитчат» картинку.
- Бегущая строка цитирует Кейна, Помни, Рагату, Джекса; перечисляются эпизоды и Glitch Productions.

## Доступность

- `prefers-reduced-motion` отключает тяжёлые анимации.
- Кнопка ловится с клавиатуры (Tab → Enter), несмотря на убегание мышью.
- У всех картинок осмысленный `alt`.

## Замена фото

Файлы лежат в `assets/characters/`. Имена подставлены в `<img class="card__photo" src="...">`. Просто перезаписывай файлы — стили и глитч-фильтры подхватятся автоматически.
