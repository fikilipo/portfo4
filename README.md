# УДИВИТЕЛЬНЫЙ ЦИФРОВОЙ ЦИРК — иммерсивный сайт

Интерактивный сайт-погружение по вселенной *The Amazing Digital Circus* (Glitch Productions).
Чистый стек: **HTML5 + CSS3 + Vanilla JS**, без библиотек и сборщиков.

## Запуск

Просто открой `index.html` в браузере. Никаких зависимостей и шагов сборки.

Локально удобно поднять статический сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Структура

- `index.html` — разметка страницы (hero, Caine, карточки узников, footer).
- `index.css` — все стили: палитра «Бездны», CRT-плёнка, глитч-заголовок, карточки, анимации.
- `App.js` — Vanilla JS: подмена символов в заголовке, слежение глаз Кейна, убегающая кнопка «ВЫХОД», глобальный CRT-сбой при клике.
- `TZ` — техническое задание.

## Реализованные фичи (по ТЗ)

1. **Глитч-заголовок** «УДИВИТЕЛЬНЫЙ ЦИФРОВОЙ ЦИРК» — `@keyframes` RGB-split (`text-shadow`), периодический `transform: skew()` с `will-change`, на hover JS подменяет буквы случайными глитч-символами. Плюс «амбиентный» сбой раз в 6–10 сек.
2. **Кейн следит за тобой** — челюсть с глазами на чистом SVG/CSS. Зрачки и блики двигаются за курсором; при резком рывке глаза краснеют и трясутся (класс `.is-broken`).
3. **Убегающая кнопка «ВЫХОД»** — на `mouseover` (и при приближении курсора) телепортируется в случайную точку через плавный CSS `transition`. Клик — `alert("ОТСЮДА НЕТ ВЫХОДА!")`. Доступна с клавиатуры (Tab + Enter).
4. **Карточки узников** — `<img>` с placeholder-URL и осмысленным `alt`. На hover — `hue-rotate / saturate / contrast / blur`-фильтры и `clip-path`-глитч анимация.
5. **Глобальный сбой при клике** — на 0.7с поверх сайта включается слой с CRT-шумом и RGB-сдвигом.

## Доступность

- Поддерживается `prefers-reduced-motion`: тяжёлые анимации отключаются.
- Все интерактивные элементы — нативные `<button>` / `<a>`, доступны с клавиатуры.
- У изображений описательный `alt`.

## Замена плейсхолдеров на реальные фото

В карточках используются URL вида `https://placehold.co/600x800/...`. Поменяй `src` в `index.html` на реальные фото персонажей — остальное (фильтры, кадрирование, glitch) уже работает.
